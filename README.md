# Changelog

Changelog Component

A responsive changelog UI component, built for the roadmap.sh Changelog Component project. This project focuses on CSS positioning and layout — using position: relative / absolute to build a vertical timeline of update entries.

Live Demo

Add your deployed link here once hosted (see Deployment below).

Features
Vertical timeline layout built with CSS positioning (relative / absolute)
Color-coded tags for change types: New, Improved, Fixed
Responsive, single-column layout that scales down cleanly to mobile
Semantic HTML using <article> and <time> elements
Google Fonts: Fraunces (headings) and Work Sans (body)
Tech Stack
HTML5
CSS3 (positioning, pseudo-elements, Flexbox, media queries)
